## 🚨 Symptoms of a Broken Game Collection

Before you add another game, check whether your collection suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Games don't load | Broken routing | Catalog loader |
| 🐌 Slow homepage | All games loaded | Lazy iframe |
| 🧊 Controls broken | Per-game input | Shared input module |
| 🔥 Scores lost | No storage | LocalStorage |
| 📉 Mobile unusable | Fixed layout | Responsive grid |
| 🔇 No search | Flat list | Tag-based filter |

> **💡 Tip:** If games don't load, it's almost always a broken relative path in the catalog — use relative URLs.
